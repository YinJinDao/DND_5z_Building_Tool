# 规则形式化

> 状态：未开始 | 依赖：`docs/` 中的规则资料 | 最后更新：2026-10-23
> 本目录负责把 dnd5z 规则书转成可计算、可校验、可被工具和 AI 使用的结构化规则。规则原文与原始资料放在 `docs/`。

## 定位

- **输入**：`docs/` 中的规则书、私设说明、勘误等原始资料。
- **输出**：结构化的规则数据、字段约定、效果的计算语义、验证样例。
- **不是**：原始资料的堆放处；原作内容仍以 `docs/` 为准。

## 当前范围

只覆盖打击者（`Striker`）伤害链路所需的规则子集，例如：

- 攻击判定、AC、命中
- 豁免、伤害类型、抗性/免疫/易伤
- 行动经济（动作、附赠动作、反应）
- 职业/专长/法术/装备中与伤害或攻击相关的效果
- 资源消耗与恢复

范围外的规则暂不形式化；新增范围时先更新本节。

## 工作原则

1. **原文可追溯**：每个规则条目标注 `docs/` 中的出处（文件 + 章节/页码）。
2. **结构化**：给实体统一 ID 和字段，术语使用 `docs/术语表.md` 中的英文标识符。
3. **计算语义明确**：写清楚该条目在攻击、豁免、伤害、资源等环节如何参与计算。
4. **可验证**：每个模块配手工样例或对拍用例，结果可复现。
5. **歧义留痕**：规则书未写清或私设冲突的地方，记录裁定理由，并链接到 `plans/决策记录.md`。
