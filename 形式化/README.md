# 规则形式化

> 状态：方案草稿待评审 | 最后更新：2026-10-23
> 本目录用于把 dnd5z 规则书转成可计算、可校验、可被工具和 AI 使用的结构化规则。原始资料在 `docs/`。

## 范围

当前只覆盖打击者（`Striker`）伤害链路所需的规则子集，例如攻击、AC、豁免、伤害类型、行动经济、资源等。范围外的规则按需扩展。
