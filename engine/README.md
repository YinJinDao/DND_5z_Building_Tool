# engine —— 打桩伤害引擎

> 状态：v0.1（可运行，自检通过） | 依赖：[../形式化/方案-打桩伤害链.md](../形式化/方案-打桩伤害链.md) | 最后更新：2026-10-23

实现方案 §6 的伤害结算管线。当前只覆盖**单次攻击的期望伤害**，即一期的核心计算单元。

## 文件

| 文件 | 作用 |
| --- | --- |
| `evaluator.py` | 伤害管线：命中率/重击率、按类型分账、目标端结算 |
| `selftest.py` | 自检：解析解 vs 蒙特卡洛，以及规则书中的结算顺序断言 |
| `demo.py` | 端到端演示：狂战士 4 级单次攻击的四组对比 |

## 运行

```bash
python -I engine/selftest.py   # 自检
python -I engine/demo.py       # 演示
```

## 已实现

- **命中率与重击率**：优势层数为整数，n 重优势 = 掷 n+1 枚 d20 取最高；劣势同理取最低；逐重抵消。
- **重击**：d20 ≥ 21 − 重击范围，且必须同时命中。重击只翻伤害骰，不翻固定加值（按 `crit_doubles` 逐项控制）。
- **按类型分账**：抗性/易伤/免疫/吸收都按伤害类型作用，不同类型分别结算后求和。
- **目标端顺序**：抗性前减伤 → 抗性（向下取整取半）→ 易伤（×2）→ 抗性后减伤 → 吸收/免疫。
- **精确算术**：全程 `Fraction`，避免浮点误差。

## 自检判据

不用固定相对阈值比对蒙特卡洛。抽样噪声随方差变化，固定阈值会把正常抖动误判为失败
（实测某一项偏差 0.36%，而该项标准误恰为 0.31%，属于 1.2σ 的正常波动）。

改为**按标准误判定**：偏离不超过 4 倍标准误即视为一致，并在输出中打印实际 σ 倍数。
真正的语义错误会远超这个范围。

## 演示结果（狂战士 L4，巨斧 1d12，目标 AC 15）

| 场景 | 命中率 | 重击率 | 期望伤害 | 相对基准 |
| --- | --- | --- | --- | --- |
| 常规 · 不用威力攻击 | 55.00% | 5.00% | 6.650 | — |
| 常规 · 用威力攻击 | 30.00% | 5.00% | 7.375 | +10.9% |
| 鲁莽攻击 · 不用威力攻击 | 79.75% | 9.75% | 9.805 | +47.4% |
| 鲁莽攻击 · 用威力攻击 | 51.00% | 9.75% | 12.619 | +89.8% |

这张表本身就是一个可用的结论：**威力攻击在有优势时收益远高于无优势时**。因为
-5 命中被优势抬高的命中率部分抵消，而伤害加值是固定的 12 点。工具输出的正是这种交互。
