# engine —— 打桩伤害引擎

> 状态：v0.1（可运行，自检通过） | 依赖：[../形式化/方案-打桩伤害链.md](../形式化/方案-打桩伤害链.md) | 最后更新：2026-10-23

实现方案 §6 的伤害结算管线。当前只覆盖**单次攻击的期望伤害**，即一期的核心计算单元。

## 文件

| 文件 | 作用 |
| --- | --- |
| `calculator.py` | **伤害计算器（一期）**：三份固定格式输入 → 期望伤害 + 输入追溯 |
| `character.py` | 基础数值：构筑 → 派生值（属性/熟练/AC/HP/豁免/攻击加值） |
| `evaluator.py` | 伤害管线：命中率/重击率、按类型分账、目标端结算 |
| `combat.py` | 战斗状态、距离与移动、动作经济校验、资源时钟、豁免型伤害 |
| `strategy.py` | 条件策略：命中/重击结果树求值、资源可行性校验 |
| `selftest.py` | 自检，11 组共 50 项断言 |
| `demo.py` | 端到端演示：构筑 → 派生值 → 期望伤害 |

## 基础数值与命中：当前的处理方式

引擎分成两层，**数值从哪来**与**数值怎么算**是分开的。

### 基础数值（`character.py`）

从 `Build` 推导 `Derived`：

```
购点基础值 + 种族 + 升级 + 专长 + 装备  →  属性值  →  调整值 (值−10)//2
等级                                  →  熟练加值 2+(等级−1)//4
护甲类型 + 熟练 + 敏捷/体质/感知      →  AC
生命骰 + 等级 + 体质调整值             →  生命值上限
属性调整值 + (熟练项 ? 熟练加值 : 0)   →  六项豁免
```

**5z 与 5e 的一处差异**：5z 的 AC 一律含熟练加值（无甲 `8+熟练+敏捷`、轻甲 `10+熟练+敏捷`、中甲 `13+熟练+敏捷(上限2)`、重甲 `16+熟练`）。照 5e 的公式写会系统性偏低。

**所有派生值都保留构成项**，不是裸数字。攻击加值必须能打印成
`力量调整值+3 + 熟练加值+2 + 武器增强+1 = +6`。
这是 `整体目标` §5「能说明分数来自哪些假设与计算」的硬性要求。

### 命中（`evaluator.py`）

```
t_hit  = AC − 攻击加值
t_crit = 21 − 重击范围
t_both = max(t_hit, t_crit)          # 重击必须同时命中

n 重优势(n≥0):  P_hit = 1 − (1−p)^(n+1)     # 掷 n+1 枚 d20 取最高
k 重劣势(n<0):  P_hit = p^(k+1)              # 取最低
```

要点：
- 攻击加值是一个整体，引擎不关心它由什么构成——构成在 `character.py` 里记录。
- 优势是**整数层**，逐重抵消；不是布尔值。
- 重击概率用 `max(t_hit, t_crit)` 计算，即未命中时不可能重击。
- 重击只翻伤害骰，不翻固定加值（逐项由 `crit_doubles` 控制）。
- 当前**不建模**「d20 掷出 1 自动失手 / 20 自动命中」——那是规则书标注的可选变体，非默认规则。

## 已实现

- **命中率与重击率**：优势层数为整数，n 重优势 = 掷 n+1 枚 d20 取最高；劣势同理取最低；逐重抵消。
- **重击**：d20 ≥ 21 − 重击范围，且必须同时命中。重击只翻伤害骰，不翻固定加值（按 `crit_doubles` 逐项控制）。
- **按类型分账**：抗性/易伤/免疫/吸收都按伤害类型作用，不同类型分别结算后求和。
- **目标端顺序**：抗性前减伤 → 抗性（向下取整取半）→ 易伤（×2）→ 抗性后减伤 → 吸收/免疫。
- **精确算术**：全程 `Fraction`，避免浮点误差。

- **距离与移动**：`CombatState` 追踪相对距离与移动力；`RangeProfile` 判定触及/射程；冲锋所需的直线移动量由 `travel_this_turn` 累计。
- **多攻击**：`evaluate_turn` 接受任意长度的攻击序列，枚举 3^k 个结果叶子（k=8 时 6561 个）。
- **条件策略**：`Rule` 按决策时点（失手/命中/重击）分支，可加骰、可影响后续攻击的优势层数，并可声明资源消耗。
- **动作经济校验**：槽位重复、动作组内插入附赠动作、替换攻击超额——三类违规均可检出。
- **豁免型伤害**：`expected_save_damage` 支持无伤与半伤两种失败分支，半伤按向下取整处理。

- **资源时钟**：`ResourcePool` 按恢复节奏展开有效容量（短休池 ×(短休数+1)、超级战技每两次长休、每回合门控）；`Budget.check_schedule` 同时校验总量与单轮上限。

## 自检判据

不用固定相对阈值比对蒙特卡洛。抽样噪声随方差变化，固定阈值会把正常抖动误判为失败
（实测某一项偏差 0.36%，而该项标准误恰为 0.31%，属于 1.2σ 的正常波动）。

改为**按标准误判定**：偏离不超过 4 倍标准误即视为一致，并在输出中打印实际 σ 倍数。
真正的语义错误会远超这个范围。
