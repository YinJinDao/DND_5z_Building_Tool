# 术语表

> 本文件是全项目术语与英文标识符的唯一来源，随讨论和开发实时更新。
> 约定：新词先登记再使用；同义词合并到同一词条；英文标识符用于代码、数据字段和跨文档引用，一旦被代码引用，改名需在 `plans/决策记录.md` 登记。
> 英文标识符当前按实体名记录，具体代码命名风格（PascalCase / snake_case 等）在开始编码时确定。

## 核心术语

| 中文 | 英文标识符 | 定义 | 备注 / 出处 |
| --- | --- | --- | --- |
| dnd5z / 5z | `dnd5z` | DND 5e 的朱雀私设规则 | 项目的规则基础 |
| 打击者 / 菜刀 | `Striker` | 以输出伤害为主要构筑目的的角色 | 当前只研究这一类 |
| 输出环境 | `Encounter`（候选） | 评估输出时面对的敌人与场景条件，如敌人 AC、豁免、抗性等 | 英文名待定；也可考虑 `TargetProfile` |
| 构筑 | `Build` | 人物数据与能力选择的总和，包括种族、职业、专长、装备、法术等 | 字段待形式化 |
| 策略 | `Strategy` | 格式化的行动方式，描述角色在战斗中的行为 | 表示粒度待定 |
| 评分 | `Score` | 对构筑/策略在给定输出环境下伤害表现的评价结果 | 基于伤害；口径待定 |
| 求解 | `Solve` / `Solver` | 在给定搜索空间中寻找最优或近似最优解 |  |
| 最优解 | `Optimum` | 在明确目标函数和搜索空间下的最优结果 |  |
| 规则形式化 | `RuleFormalization` | 把规则书转成可计算、可校验的结构化数据与语义 | 见 `形式化/` |
| 阶段 | `Stage` | 有明确目标和验收标准的一次开发单元；数量与边界不预设 | 见 `plans/阶段/` |

## 规则与战斗术语

| 中文 | 英文标识符 | 定义 | 备注 / 出处 |
| --- | --- | --- | --- |
| 伤害 | `Damage` | 攻击或效果造成的数值损失 |  |
| 伤害类型 | `DamageType` | 伤害的属性类别，如挥砍、火焰、力场等 |  |
| 命中 | `Hit` | 攻击检定达到或超过目标 AC 的结果 |  |
| 暴击 | `CriticalHit` | 攻击骰出特定结果后触发的额外伤害 | 具体规则以 5z 为准 |
| 护甲等级 | `ArmorClass` / `AC` | 攻击是否命中的防御值 |  |
| 豁免 | `SavingThrow` | 对抗法术或效果时使用的豁免检定 |  |
| 行动经济 | `ActionEconomy` | 动作、附赠动作、反应等行动资源的使用结构 |  |
| 回合 | `Turn` | 单个角色在其行动顺序中的行动时段 |  |
| 轮 | `Round` | 所有参战者各行动一次的时间单位 |  |
| 期望伤害 | `ExpectedDamage` | 按概率加权的平均伤害 |  |
| 每轮伤害 | `DamagePerRound` / `DPR` | 每轮造成的伤害量 | 常用比较指标 |
| 资源 | `Resource` | 有限次数的职业、法术或装备能力 |  |
| 增益 / 减益 | `Buff` / `Debuff` | 对角色有利/不利的持续效果 |  |
| 抗性 / 免疫 / 易伤 | `Resistance` / `Immunity` / `Vulnerability` | 对特定伤害类型的减免/无效/增伤 |  |

## 登记规则

1. 新术语在首次使用的同一次修改中写入本表。
2. 中文同义词写在同一个词条，例如“打击者 / 菜刀”。
3. 英文标识符优先使用代码中实际采用的拼写；尚未确定时标“候选”。
4. 术语改名时，同步更新引用它的文档，并在 `plans/决策记录.md` 登记。
