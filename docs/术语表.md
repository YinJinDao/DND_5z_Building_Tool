# 术语表

> 本文件是全项目术语与英文标识符的参考，随讨论和开发更新。
> 新词可顺手登记；同义词尽量合并到同一词条；英文标识符被代码引用后，改名时同步引用处。
> 英文标识符当前按实体名记录，具体代码命名风格（PascalCase / snake_case 等）在开始编码时确定。

## 核心术语

| 中文 | 英文标识符 | 定义 | 备注 / 出处 |
| --- | --- | --- | --- |
| dnd5z / 5z | `dnd5z` | DND 5e 的朱雀私设规则 | 项目的规则基础 |
| 打击者 / 菜刀 | `Striker` | 以输出伤害为主要构筑目的的角色 | 当前只研究这一类 |
| 输出环境 | `Encounter`（候选） | 评估输出时面对的敌人与场景条件，如敌人 AC、豁免、抗性等 | 英文名待定；也可考虑 `TargetProfile` |
| 构筑 | `Build` | 人物数据与能力选择的总和，包括种族、职业、专长、装备、法术等 | 字段待形式化 |
| 策略 | `Strategy` | 格式化的行动方式，描述角色在战斗中的行为 | 表示粒度待定 |
| 评分 | `Score` | 对构筑/策略在给定输出环境下伤害表现的评价结果 | 基于伤害；口径待定 |
| 求解 | `Solve` / `Solver` | 在给定搜索空间中寻找最优或近似最优解 |  |
| 最优解 | `Optimum` | 在明确目标函数和搜索空间下的最优结果 |  |
| 规则形式化 | `RuleFormalization` | 把规则书转成可计算、可校验的结构化数据与语义 | 见 `形式化/` |
| 阶段 | `Stage` | 有明确目标和验收标准的一次开发单元；数量与边界不预设 | 见 `plans/阶段/` |

## 规则与战斗术语

| 中文 | 英文标识符 | 定义 | 备注 / 出处 |
| --- | --- | --- | --- |
| 伤害 | `Damage` | 攻击或效果造成的数值损失 |  |
| 伤害类型 | `DamageType` | 伤害的属性类别，如挥砍、火焰、力场等 |  |
| 命中 | `Hit` | 攻击检定达到或超过目标 AC 的结果 |  |
| 重击 / 暴击 | `CriticalHit` | 攻击检定 d20 ≥ 21 − 重击范围时触发，全部伤害骰掷两次 | 规则书用“重击”，本表原记作“暴击”；细节见下方专有术语 |
| 护甲等级 | `ArmorClass` / `AC` | 攻击是否命中的防御值 |  |
| 豁免 | `SavingThrow` | 对抗法术或效果时使用的豁免检定 |  |
| 行动经济 | `ActionEconomy` | 动作、附赠动作、反应等行动资源的使用结构 |  |
| 回合 | `Turn` | 单个角色在其行动顺序中的行动时段 |  |
| 轮 | `Round` | 所有参战者各行动一次的时间单位 |  |
| 期望伤害 | `ExpectedDamage` | 按概率加权的平均伤害 |  |
| 每轮伤害 | `DamagePerRound` / `DPR` | 每轮造成的伤害量 | 常用比较指标 |
| 资源 | `Resource` | 有限次数的职业、法术或装备能力 |  |
| 增益 / 减益 | `Buff` / `Debuff` | 对角色有利/不利的持续效果 |  |
| 抗性 / 免疫 / 易伤 / 吸收 | `Resistance` / `Immunity` / `Vulnerability` / `Absorption` | 对特定伤害类型的减免/无效/增伤/转治疗 | 吸收为 5z 特有，见下节 |

## 方案与评价术语

| 中文 | 英文标识符 | 定义 | 备注 / 出处 |
| --- | --- | --- | --- |
| 评价维度 | `EvaluationDimension` | 评价构筑时考察的方面 | 云端方案草稿用语 |
| 伤害值 | `DamageValue` | 评价体系中的最终指标 | 云端方案草稿用语 |
| 资源消耗量 | `ResourceConsumption` | 评估时假设消耗的资源量 | 云端方案草稿用语 |
| 输出轮次 | `OutputRounds`（候选） | 评估伤害时固定的战斗轮数 | 云端方案草稿用语；英文名待定 |
| 权重 | `Weight` | 多个输出环境综合评分时各环境的占比 | 云端方案草稿四期 |
| 综合评分 | `CompositeScore`（候选） | 多个环境或维度加权后的总分 | 云端方案草稿四期 |
| 战斗求解器 | `CombatSolver` | 输入环境/构筑/策略并输出评分或最优解的打包工具 | 云端方案草稿二期后 |

## 5z 专有术语（伤害链路）

> 通用 5e 术语表未覆盖、但伤害链路形式化必需的条目。定义按规则书 v1.63 原文整理，出处与影响见 `形式化/方案-打桩伤害链.md` 附录 A。

| 中文 | 英文标识符 | 定义 | 备注 / 出处 |
| --- | --- | --- | --- |
| 重击范围 | `CriticalRange` | 触发重击的 d20 阈值余量，默认 1（即 d20 ≥ 20） | 基础/发动攻击 |
| 优势层数 | `AdvantageTier` | 优/劣势的整数层数：n 重优势额外骰 n 枚 d20 取最高，优劣势逐重抵消 | 与 5e 的布尔优劣势不同 |
| 吸收 | `Absorption` | 第四类伤害减免：取消该类型伤害并转为等量治疗，优先级高于免疫 | 基础/伤害与治疗 |
| 抗性前减伤 | `PreResistReduction` | 在抗性与易伤之前扣减的固定值（如“所有伤害减少 5 的灵光”） | 与抗性后减伤顺序不可互换 |
| 抗性后减伤 | `PostResistReduction` | 在抗性与易伤之后扣减的固定值（如战斗风格“拦截”） | 基础/伤害与治疗 |
| 伤害槽 | `DamageSlot` | 伤害的命名构成项：武器骰 / 属性 / 熟练 / 体型 / 专长 / 战技 / 骰池等 | 部分规则按槽“忽略”或“仅作用于” |
| 卓越骰 | `SuperiorityDie` | 战技共用资源，短休或长休回满；骰面 d4 → d6(5级) → d8(11级) → d10(17级) | 专长/战技专长 |
| 战技 | `Maneuver` | 以卓越骰或替换攻击发动的招式，分五流派、四级 | 专长/战技专长 |
| 超级战技 | `SuperManeuver` | 不耗卓越骰，次数 = floor(卓越骰 / 10)，每两次长休恢复 | 通过物品获得的卓越骰不计入次数 |
| 流派 | `ManeuverSchool` | 开山 / 游龙 / 摘星 / 混元 / 神机 | 决定战技的关键属性 |
| 武器媒介 | `WeaponMedium` | 战技要求使用的武器或徒手 | 决定触及与豁免 DC 加值 |
| 替换攻击 | `ReplaceAttack` | 战技占用攻击动作内基础攻击次数的方式 | 不可替换加速术、附赠动作等给予的攻击 |
| 准备战技 | `PreparedManeuver` | 长/短休时选定、战斗中可发动的战技集合 | 数量 = 角色等级 + 关键属性调整值 |
| 变体 | `Variant` | 玩家可选变体，重新定义既有条目的行为而非新增条目 | 如“疾风狂暴”“爆发式卓越骰” |
| 目标档案 | `TargetProfile` | 打桩评估中的目标侧参数集（AC、豁免、抗性等） | 建议替代候选名 `Encounter`；打桩下不存在“遭遇” |

## 使用建议

- 新术语可顺手补充，避免后续歧义。
- 中文同义词合并到同一词条，例如“打击者 / 菜刀”。
- 英文标识符优先使用代码中实际采用的拼写；尚未确定时标“候选”。
- 术语改名时，尽量同步引用它的文档。
