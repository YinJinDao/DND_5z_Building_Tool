## 阶段规则

- **不预设阶段数量和内容**。阶段是“有明确目标和验收标准的一次开发单元”，不是固定路线图。
- 开始阶段时，复制 `阶段/_模板.md` 为 `阶段/NN-名称.md`；`NN` 只是创建顺序，用于排序，不代表固定编号。
- 阶段文档只写本阶段的目标、做法和验收；跨阶段内容放 `整体目标.md`，稳定后再单独建文档。
- 阶段结束或废弃时，在文件头标记状态；重大变化写入 `决策记录.md`。
- 允许推翻已有阶段划分；推翻时保留旧的决策记录，不重写历史。

## 文档约定

1. **单一事实来源**：术语在 `docs/术语表.md`；规则在 `形式化/`；决策在 `决策记录.md`；目标在 `整体目标.md`。其他文档只引用，不复制。
2. **术语先行**：新词先登记再使用；同义词合并；相关文档与术语表在同一次修改中更新。
3. **文件头**：每个文档以 `> 状态 | 依赖 | 最后更新` 开头。
4. **阶段文档模板**：目标与边界、输入/输出、做法与取舍、验收标准、风险与未知、待确认问题。
5. **语言**：文档用中文；代码、数据字段和跨文档引用使用 `docs/术语表.md` 中的英文标识符。
6. **小步修改**：大改前先在 `决策记录.md` 记一条决策，再改文档。

## 变更机制

- 目标/范围变化 → 更新 `整体目标.md`，并在 `决策记录.md` 登记。
- 新增/修改术语 → 立即更新 `docs/术语表.md`，同步引用处。
- 规则歧义裁定 → 在 `形式化/` 对应条目记录，并链接到 `决策记录.md`。
- 阶段拆分/合并/废弃 → 在 `决策记录.md` 登记，阶段文档保留状态标记。
